# ChunkCarve v1.0.5 — 紫水晶轮廓与黑边修复

## 关于 1.0.4 紫水晶导出问题的声明

1.0.4 发布包仍存在紫水晶簇及大、中、小型紫晶芽的导出缺陷：程序把这些非完整方块识别为完整立方体，贴图的透明部分在拓竹等切片软件中显示为黑色边缘；装饰轮廓侧面也可能采样到透明黑色像素。

这是 ChunkCarve 的导出处理缺陷。对此给大家带来的困扰，我们表示歉意。**1.0.5 已修复该问题；旧版本导出的 GLB / OBJ 需要从原存档重新导出。升级程序不会自动修复已有模型文件。**

## 本次修复

- 紫水晶簇、大型紫晶芽、中型紫晶芽和小型紫晶芽按官方模型的可见轮廓导出，支持六个朝向。
- 裁去透明区域，为轮廓生成有厚度的实体；侧边使用原贴图中的不透明像素颜色，避免透明黑边。
- 标准、8×8、16×16 三档导出均保留晶体的像素实体，避免重复细分和小尺寸面片丢失。
- 保留 1.0.4 对 Minecraft 26.1+ 存档目录和 26.3 方块状态格式的兼容修复。

## 下载与升级

下载 [ChunkCarve-v1.0.5-win64.zip](https://github.com/Cangminghai/chunkcarve/releases/download/v1.0.5/ChunkCarve-v1.0.5-win64.zip)，完整解压到新文件夹，运行 `ChunkCarve.exe`，重新打开原存档。导出紫水晶时保留默认勾选的「交叉面／贴图装饰」。

如果需要保留旧版项目列表，可以在关闭程序后将旧程序目录里的 `projects.json` 复制到新程序目录。存档继续使用原路径，无需移动或修改。

## 验证范围

- 使用官方 Minecraft 26.3 服务端生成的存档和同版本官方客户端资源，放置四种晶体的六个朝向。
- 对每种晶体和朝向分别检查 1、2、4 mm/格，以及标准、8×8、16×16 细分，共 **216 组 GLB 导出**：晶体轮廓保留、网格闭合、表面采样均落在不透明像素上。
- Windows 打包程序的实际预览和导出按钮验证通过；三档 GLB 经本机 **Bambu Studio 02.09.01.70** 导入，均报告为闭合网格。
- **236 项 Python 测试、3 项项目中心回归测试通过。**以上验证覆盖模型与导入，不包含实体打印验证。
