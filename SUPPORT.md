# Support

For installation, configuration, or usage questions, open a GitHub issue using the appropriate template and include:

- ChunkCarve version and operating system
- Python version and launch method
- Minecraft version and launcher type
- Reproduction steps and relevant error text

Remove usernames, absolute paths, save names, access tokens, and other personal information before posting logs. Do not upload Minecraft saves or game assets.

For security vulnerabilities, follow [SECURITY.md](SECURITY.md) and do not open a public issue.
